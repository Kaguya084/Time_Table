## 这是什么

校园里的时间信息散落在四五个地方、格式各异，全靠脑子记。手机日历能提醒，却认不出群聊里的"10 月 31 号比赛"——**非结构化信息进不了日历，这才是断点**。

本项目的定位很明确：**不做日历，做日历的上游。** iOS 原生日历已经够好，缺的只是谁来喂数据。于是做成一条流水线：

- **连小理（AI 搭档）负责「想」**：解析通知、规划时间、识别冲突、生成结构化数据。
- **网页只负责「看和点」**：打包解析请求、给人逐条核对、导出 `.ics`。网页里没有智能——不解析、不规划、不生成。

判断标准：拿掉连小理，剩下的部分与原生日历无异。

## 功能特性

- **四类日程，各自独立日历**：课表 / 活动 / DDL / 个人，导出后是四个可在 iPhone 上分别开关的日历。
- **课表只读，其余可改**：课表有权威源（教务系统），改了也没用；活动、DDL、个人没有权威源，支持增删改。
- **先预览、后写入**：连小理的解析结果先出预览，逐条人眼核对再确认导入。
- **信息不全不编造**：时间 / 地点缺失时标「待确认」而不是替你编一个，保证结果可信。
- **重复日程是一条规则**："每个工作日 6:40 早训"生成带 `RRULE` 的一条系列，不是几十条独立事项。
- **数据全在本机**：不联网、不经过任何服务器，所有数据存在浏览器本地。
- **🌟 一键演示数据**：首次打开为空白，内置一键注入全功能演示课表，降低评委/用户体验门槛。
- **📅 真·无限日历**：解除传统 18 周限制，支持无限翻阅；点击顶部「第 X 周」可直接输入跳转；未开学自动显示提示。
- **⚙️ 学期自定义设置**：随时在「其他」页修改第一周周一日期，全局日历与周次自动联动。
- **📥 订阅外部日历**：支持 `.ics` 订阅链接下载及本地导入（如法定节假日），并带有专属开关和颜色。
- **🌓 主题无缝切换**：支持白天、暗黑、跟随系统三种模式，适配极客深夜使用场景。

## 使用流程

1. **导入课表**：电脑打开网页 → 「复制课程表解析请求」，连同教务系统导出的 PDF / 截图发给连小理 → 它返回 JSON → 粘回网页 → 先预览逐条核对 → 确认导入。
2. **导入事项**：把群通知原文粘进网页 → 生成解析请求（自动带上"今天第几周、第一周周一日期"）→ 连小理返回事项 → 预览核对 → 确认导入。
3. **手机接力**：电脑端「复制全部数据」，手机打开同一网址「粘贴并恢复」。两端数据各自独立，靠这一步接力（数据按网址隔离）。
4. **导出到 iPhone**：按类导出四个 `.ics`（课程表 / 活动 / DDL / 个人），用文件 App 或邮件导入 iPhone 日历，得到四个可开关的日历。

> ⚠️ **iOS 导入只有「新增」、没有「更新」。**
> 某类日程改过后，先在 iPhone 上删掉那一类日历，再重新导入该类 `.ics`。整套流程就是按这个语义设计的。

## 部署

本仓库是一个**零依赖、零构建的单文件静态站**——整个应用就是 `index.html`（HTML + CSS + JS 全部内联），不引用任何外部资源、不发任何网络请求。

直接用 `index.html` 作为 GitHub Pages 的根页面即可：

1. 把 `index.html` 放进仓库根目录（或 `docs/`，并在 Pages 设置里选择它）。
2. 仓库 **Settings → Pages** → 选择对应分支与目录。
3. 等待构建完成，访问 `https://kaguya084.github.io/Time_Table/`。

网页本体是「空壳」：不含任何课表 / 个人信息，所有数据由使用者自行导入。

> ⚠️ **数据按网址隔离**——换域名 / 换路径 = 换一份空数据。迁移前先「复制全部数据」。
>
> 💡 **剪贴板 API** 需要安全上下文（HTTPS 或 localhost）。GitHub Pages 满足；本地用 `file://` 打开会自动走降级方案。

## 数据与安全

- **不收集**：没有后端、没有统计、没有任何网络请求。打开网页源码搜不到一个 `fetch` 或外链。
- **本地存储**：课表、事项、基线记录都存在浏览器 `localStorage`，按网址隔离。
- **迁移**：换设备或换网址前，用「其他 → 数据备份 / 迁移」里的「复制全部数据」导出，到新地址「粘贴并恢复」。
- **老数据修复**：若用旧版存过数据、升级后「日程表」打不开，去「其他」页签点「为老数据补空白默认值」。

## 已知限制

- **数据不跨设备同步**——存在浏览器本地，换设备 / 清缓存 / 换网址都会丢，靠备份 JSON 迁移。
- **课表只读**——权威来源是教务系统，网页内不提供编辑；调课停课请改好后重新导入。
- **ics 反推周次**依赖当前设置的「第一周周一」，学期不符时请在设置中手动调整。
